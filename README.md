# 📖 Cozy Chibi Portfolio

Welcome to my personal developer journal and portfolio site! Built around a warm pastel aesthetic, this site features custom physics-based scroll transitions, a realistic 3D book-flip project viewer, and a hand-drawn interactive stickers toolkit.

## ✨ Key Features

- **📖 Realistic 3D Notebook Flip**: The Projects section splits content into left and right pages, performing hardware-accelerated 3D sheet-flips over metal binder coils when paging through builds.
- **🛹 Scroll-Bound Chibi Transitions**: Features custom winking chibi developer character animations that glide and skate left-to-right across section spacer dividers.
- **🎨 Cozy Aesthetic**: Styled with custom cream backgrounds, rounded outlines, drop shadows, and hand-drawn doodles powered by Tailwind CSS and Framer Motion.
- **📱 Fully Responsive**: Custom layouts adapted for smooth desktop dual-page reading, tablet stacks, and mobile single-column experiences.

## 🚀 Running Locally

Follow these commands to install dependencies and run the development server on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/MonikaS05/MonikaShankar.git
   cd MonikaShankar
   ```

2. **Install node packages**:
   ```bash
   npm install
   ```

3. **Start the local dev server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build production bundle**:
   ```bash
   npm run build
   ```
